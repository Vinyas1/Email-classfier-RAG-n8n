# VPN password reset procedure

1. Verify the employee's identity via their manager or HR record.
2. Send a one-time reset link to the employee's registered company email.
3. Ask the employee to set a new password meeting the 12-character policy.
4. Confirm VPN connectivity by asking them to connect and reach an internal resource.
5. If MFA is also locked, escalate to the security team - do not reset MFA directly.

Typical resolution time: under 15 minutes.
